# الاختبارات

تشغيل: `flutter test`

| الملف | يغطي |
|---|---|
| unit/questions_test | 72 سؤالًا، 24/36/12، المعرفات، الأقطاب والأنماط والمحاور، العكسية |
| unit/scoring_test | معادلات MBTI/Enneagram/A-R-F-D، العكسي، التعادل والتقارب، التحقق، الحتمية |
| unit/local_store_test | حفظ/استعادة التقدم، بيانات تالفة، افتراضيات الموافقة |
| unit/assessment_notifier_test | منع النتيجة قبل الاكتمال، استعادة بعد إعادة التشغيل |
| unit/ad_service_test | التعطيل يمنع التحميل، فشل الإعلان لا يعطل، حظر الأسئلة، حدود الـ interstitial |
| unit/offline_sync_test | العمل دون إنترنت/Supabase، فشل الشبكة لا يرمي |
| unit/plan_report_test | الخطة، التقرير، عدم اختلاق التناقضات، حمولة AI بلا إجابات خام |
| widget/screens_test | RTL، الرئيسية دون طلب إعلان، تعطيل زر الحساب، شاشة السؤال |
| integration/flow_test | رحلة كاملة على مستوى الحالة (ليست اختبار جهاز) |
| unit/profile_test | مسار الحياة (9 لتاريخ 19/12/1985 والأرقام الرئيسية)، حدود الأجيال، أحداث الدول، الحيوان الأقرب |
| unit/extra_tests_test | سلامة بيانات 28 اختبارًا، المعادلات، العكسي، الأعلى، أنماط التعلّق، التحقق |
| unit/extra_store_test | حفظ نتائج الاختبارات الإضافية والملف الشخصي وتقدمها غير المكتمل ومسحها |
| widget/profile_screen_test | الملف الشخصي وتعطيل زر الحساب حتى اكتمال الإجابات |
| unit/integrated_engine_test | المحاور والثقة والاتفاق/التباين، ملاحظات الجودة، قسم الضغط، صورة الآخرين، القواعد، والاختبارات العشرة الجديدة (RIASEC، التسويف، الرفاه...) |
| widget/integrated_screen_test | أقسام التحليل المتكامل وتقييم الآخرين وصفحة النتائج |
| unit/similarity_v2_test | تطابق كتالوج الأوزان مع الاختبارات، الصيغة الموزونة، استبعاد الحساس، فحص نصي لـ SQL |
| unit/chat_images_test | فحص توقيع الصور (JPEG/PNG/WebP فقط، 2MB)، مسار التخزين، فحص نصي لـ SQL |
| unit/similarity_cache_test | فحص نصي لـ SQL الذاكرة المؤقتة: الخصوصية، التحديث عند التغيّر فقط، الحذف التلقائي |
| supabase/tests/rls_check.sql | عزل RLS يدويًا في SQL Editor |

**لم يُشغَّل أي اختبار من المؤلف** (لا Flutter في بيئة الكتابة).
